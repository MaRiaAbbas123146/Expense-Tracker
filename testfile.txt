MinIO is an S3-compatible object-storage system that can run locally or in a private environment.
I used MinIO to practice S3-compatible object storage locally without requiring an AWS account or billing setup
Boto3 is the AWS SDK for Python, and because MinIO supports the S3 API, boto3 can communicate with MinIO using S3 operations.
